# 屿光 · ISLAND TIME — 海景小岛

一座可交互的三维海景小岛：环岛观景、上岛漫步，可切换清晨 / 晴午 / 日落 / 夜晚四种时辰与晴朗 / 雨天 / 雷暴 / 狂风四种天气，带海风调节、程序化环境声与风景截图。

本仓库是站点的 1:1 静态镜像，纯静态、无需构建、无后端依赖。

## 目录结构

- `index.html` — 页面入口与首屏样式
- `assets/` — 打包后的脚本、样式、模型解密模块与几何解码器
- `draco/` — 几何解码器（备用加载路径）
- `models/` — 加密压缩后的模型资源包（运行时在浏览器内解密，需 HTTPS 或 localhost 环境）
- `textures/` — 地表材质贴图、HDR 天空与云图

## 本地预览

任意静态服务器均可，例如：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。需要支持 WebGL 2 的浏览器，并建议打开硬件加速。
